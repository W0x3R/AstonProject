## 📖 Project description:

This project is an application for viewing posts and comments based on the public API <a href = ‘https://jsonplaceholder.typicode.com/’>JSONPlaceholder.</a>, created as part of Aston's React intensive.


### 🖥️ Implemented functionality:

- Implemented the project file structure based on Feature-Sliced Design architecture.

- Configured routing (React Router) and pages: posts, users, albums, comments.

- Connected API work via RTK Query (posts, users, albums, etc.), implemented caching, request invalidation, and data loading by id.

- Configured global state via Redux Toolkit (createEntityAdapter, slices, selectors).

- Implemented functionality: modal windows (React.Portal + Compound Components), comment accordion, post filtering, lazy loading of components with fallback.

- Added ThemeContext (Provider, custom hook, theme switcher).

- Used HOC withLoading to extend components.

- Typed the project using TypeScript (data models, Props, RTK Query).

⚡ Result: SPA application with navigation, theming, API integration, and modern patterns (HOC, Compound Components, Context, Feature-Sliced Design).

## 🛠 Project installation

1. Clone the repository:

```bash
 git clone https://w0x3r.github.io/React-Intensive-Project
```

2. Go to the project folder

```
 cd React-Intensive-Project
```

3. Install dependencies

```
 npm install
```

4. Start the local server

```
npm run dev
```
